# ActionRecorder alpha 0.0.1

Консольная программа для Windows 10/11, которая в фоновом режиме собирает
глобальные события клавиатуры и мыши и записывает их в UTF-8 лог-файл.

## Требования

- Windows 10 или новее, x64
- Visual Studio 2022 (Desktop development with C++) или MSVC
- CMake 3.16+
- SDK Windows с `UIAutomation.h`

## Сборка

```powershell
cmake -S . -B build -A x64
cmake --build build --config Release
```

Исполняемый файл будет расположен в `build/Release/ActionRecorder.exe`.
Проект использует C++17, флаги `/utf-8`, `/source-charset:utf-8` и
`/execution-charset:utf-8` для MSVC.

Также сборку можно выполнить из Visual Studio: откройте корень репозитория
через «Open Folder» или сгенерируйте решение через CMake.

## Запуск

```powershell
.\build\Release\ActionRecorder.exe
```

При запуске программа выводит `ActionRecorder alpha 0.0.1`, затем запрашивает:

1. Путь для сохранения логов.
2. Имя лог-файла без расширения.

Файл создаётся как `[Имя]_[ГГГГММДД_ЧЧММСС].txt`, например:
`log_20250410_153022.txt`.

Для остановки нажмите `Ctrl+Shift+Q`. Можно закрыть консольное окно,
однако корректное завершение через сочетание клавиш освобождает хуки.

## Формат лога

Файл начинается с UTF-8 BOM (`EF BB BF`) и статичного заголовка. Каждая строка
имеет формат:

```text
[TIMESTAMP] | [OBJECT_IDENTIFIER] | [ACTION] | [DURATION_MS]
```

- `TIMESTAMP`: локальное время `ЧЧ:ММ:СС.ммм`.
- `OBJECT_IDENTIFIER`: `UIA:ControlType(Name="...", AutomationId="...")`
  при успешном UI Automation или `POS:Mouse(X=..., Y=...)` при fallback.
- `ACTION`: `KeyPress(VK_CODE)`, `KeyRelease(VK_CODE)`,
  `MouseDown(LEFT|RIGHT)`, `MouseUp(LEFT|RIGHT)`,
  `MouseClick(LEFT|RIGHT)` или `MouseMove`.
- `DURATION_MS`: длительность нажатия или интервал до предыдущего действия.

## Кодировка

Все исходные файлы должны сохраняться в UTF-8. CMake передаёт MSVC флаги UTF-8,
а консоль переключается на кодовую страницу UTF-8. Лог-файлы всегда открываются
в бинарном режиме, начинаются с BOM и содержат текст в UTF-8. Русские символы
в свойствах UI Automation `Name` и `AutomationId` должны корректно отображаться.

## Известные ограничения alpha

- Возможны пропуски событий при высокой нагрузке или старте хука в процессе
  блокировки/смены фокуса приложения.
- Долгие нажатия и последовательные действия определяются локально по таймерам.
- Низкоуровневый клавиатурный хук не позволяет надёжно восстанавливать произвольный
  ввод текста на уровне отдельных символов во всех приложениях.
- UI Automation может быть недоступен в приложениях с повышенными привилегиями
  или при использовании remote desktop/container; в этом случае используется
  координатный fallback.
- Версия предназначена для тестирования на разных конфигурациях Windows.
