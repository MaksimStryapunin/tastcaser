# Alpha 0.0.1 — First Test Release

Первый тестовый alpha-релиз ActionRecorder.

- выбор пути и имени файла через стандартный диалог Проводника;
- явный фильтр записи по исполняемому файлу целевого процесса;
- глобальные low-level хуки клавиатуры и мыши;
- UI Automation с координатным fallback;
- фиксированная кодировка UTF-8 с BOM для русского языка;
- клавиатурный текст не сохраняется: записываются только VK-коды;
- видимый консольный индикатор записи и остановка через `Ctrl+Shift+Q`.

Известные ограничения:

- возможны пропуски событий;
- UI Automation может быть недоступен для приложений с повышенными привилегиями;
- требуется тестирование на разных конфигурациях Windows.
